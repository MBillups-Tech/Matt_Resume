Position Summary
J. J. Keller is seeking a Sr. Software Engineer with strong Azure Cloud and .NET expertise to help design, develop, deploy, and support business-critical applications and cloud-based services. This role combines software development with cloud infrastructure and DevOps responsibilities, providing an opportunity to work across the full application lifecycle, from technical design and coding to deployment automation, monitoring, and production support.

 

The ideal candidate is a hands-on senior contributor who can independently own complex work from design through production, make sound implementation decisions, maintain a high bar for quality and security, troubleshoot difficult production issues, and raise the technical capability of engineers around them. They should understand not only the code they are changing, but how that change affects the larger ecosystem. They should proactively identify technical risks, improve engineering practices through example, mentory other engineers, and be capable of leading substantial development efforts without needing day-to-day technical direction.

 

Key Technologies: Angular, Azure: App Service, Functions, API Management, Service Bus, SQL Database

Job Responsibilities
Takes technical ownership of complex application capabilities from design through production, making sound implementation decisions while considering architecture, security, performance, reliability, maintainability, and downstream system impacts.
Analyzes user needs and impact to other site areas to determine technical requirements of assigned tasks.
Promotes strong quality practices by performing unit testing and providing appropriate level of support for user acceptance testing, as needed.
Follows secure coding standards and incorporates basic security-by-design principles into assigned development tasks.
Adheres to OWASP best practices to reduce common security risks such as input validation errors, insecure data handling, etc.
Maintains accurate technical documentation for assigned programming projects.
Acts as a support resource for the technical support staff to ensure that customer-reported issues are being addressed in an efficient and accurate manner.
Performs lead developer role on assigned projects.
Interfaces with Website and Database Administrators to maintain optimal server configuration, database accuracy/integrity and for coordination of staging and production moves.
Develops and maintains a solid understanding of the technology tools and trends and remains current in new technology developments and their potential impact on the department.
Proactively explores, applies, and advocates for AI-assisted and agentic development practices that improve engineering effectiveness, while ensuring generated solutions meet established standards for architecture, security, quality, maintainability, and production readiness.
