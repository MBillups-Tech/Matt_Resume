Job Description STRATEGIC STAFFING SOLUTIONS (S3) HAS AN OPENING. Senior Cloud DevOps Engineer St. Louis, MO (Remote in CST) W2 Contract role Position Overview We are seeking a Senior Cloud DevOps Engineer to design, build, automate, and continuously improve cloud infrastructure and DevOps capabilities within a Microsoft Azure environment.

This is a hands-on technical SME role responsible for advancing cloud infrastructure, CI/CD automation, deployment processes, and operational reliability. The successful candidate will bring strong technical expertise, take ownership of solutions, and help establish and improve processes and standards in a growing organization. Key Responsibilities Design, implement, manage, and optimize cloud infrastructure and services within Microsoft Azure.

Develop, maintain, and continuously improve CI/CD pipelines and automated deployment processes. Engineer and automate application build, testing, release, and deployment workflows using Azure DevOps, GitHub Actions, or similar platforms. Implement Infrastructure as Code (IaC) using Terraform, Bicep, ARM templates, or comparable technologies.

Manage cloud resources, including compute, storage, networking, identity, and security configurations. Support containerization and orchestration technologies, including Docker and Kubernetes/AKS. Establish cloud infrastructure standards, automation practices, documentation, and operational procedures.

Implement monitoring, logging, alerting, and performance optimization solutions. Troubleshoot complex infrastructure, deployment, and production issues. Advance cloud security, access management, vulnerability remediation, and DevSecOps practices.

Requirements 5+ years of progressive experience in Cloud Engineering, DevOps, Infrastructure Engineering, or a related technical discipline. Strong hands-on experience designing, implementing, and supporting Microsoft Azure environments. Demonstrated expertise developing and managing CI/CD pipelines.

Experience with Azure DevOps and/or GitHub Actions. Strong Infrastructure as Code experience, particularly Terraform or Bicep. Proficiency in scripting and automation using PowerShell, Bash, or Python.

Experience with Docker, Kubernetes, and Azure Kubernetes Service (AKS). Knowledge of cloud networking, security, identity management, and access controls. Experience with cloud monitoring, logging, troubleshooting, and production support.

Strong understanding of Git, source control, branching strategies, and release management. Ability to balance technical engineering, operational support, and continuous improvement. Exceptional verbal and written communication skills, with the ability to engage effectively across all levels of an organization.

Preferred Qualifications Microsoft Azure certifications such as AZ-104, AZ-400, or AZ-305. Experience with GitOps, Helm, Ansible, or similar technologies. Experience with cloud migrations, modernization, and optimization.

Familiarity with DevSecOps practices and cloud security standards. Experience supporting distributed or international teams. *Beware of scams.
