Position Summary
Fathom Management is seeking an experienced Senior Software Engineer / Oracle Application Developer to support enterprise-level business systems for the Department of Veterans Affairs (VA).

The successful candidate will design, develop, maintain, and modernize enterprise Oracle applications. This role requires extensive hands-on experience with Oracle Forms, Oracle Reports, advanced backend PL/SQL development, and Oracle WebLogic Server environments.

The ideal candidate will possess strong expertise in database architecture, application development, performance tuning, and legacy application support. The individual will be responsible for developing and maintaining interactive user interfaces, creating operational reports, optimizing database performance, and supporting enterprise application deployments.

This is a 100% remote position for qualified U.S.-based candidates.

Responsibilities/Skill Sets
Application Development

Design, develop, test, and implement robust client-server applications using Oracle Forms 19c.

Build, modify, debug, and maintain interactive application screens, master-detail blocks, and business layouts.

Develop, maintain, and enhance operational and business reports using Oracle Reports.

Backend Engineering

Write, optimize, and maintain complex backend database architectures, including PL/SQL packages, stored procedures, functions, custom schemas, and database triggers.

Apply advanced SQL techniques, including bulk collections, analytical functions, and structured error-handling frameworks.

Support secure and reliable relational database design.

Oracle WebLogic Administration and Tuning

Configure, manage, and troubleshoot Oracle WebLogic Server environments hosting Forms and Reports services.

Support application deployments, environment configuration, and middleware operations.

Troubleshoot application and middleware issues and support system reliability.

Database Performance Optimization

Conduct application and database performance tuning.

Refactor slow queries and optimize database execution paths.

Optimize indexes, large data loads, and application processing.

Identify opportunities to improve application performance, scalability, and maintainability.

Enterprise Application Support and Modernization

Maintain and enhance existing enterprise Oracle applications.

Participate in application upgrades, migrations, enhancements, and modernization initiatives.

Support software development lifecycle activities, version control, testing, and deployments.

Collaborate with business analysts, technical teams, and end users to resolve issues and deliver application enhancements.
